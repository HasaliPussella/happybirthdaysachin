BACKGROUND MUSIC — ADD YOUR OWN MP3

1. Put your own MP3 audio file in this folder:
   sachin-birthday/assets/music/

2. Rename the file exactly to:
   background-music.mp3

3. Keep the file in this folder (do not put it in another folder).

4. Open the website and tap “♫ Play music”. Tap again to pause.

The Play/Pause button is available on the birthday, cake, gallery and letter pages.
The music repeats automatically. The website does not include a song; you supply the MP3.

If the button says “Add your MP3 first”, check that the filename and folder are
exactly as shown above. Use an MP3 file that you own or have permission to use.
