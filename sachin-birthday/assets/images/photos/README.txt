YOUR PHOTO PLACEHOLDERS

There are six scrapbook photo spaces in pages/gallery.html.

To add your own photos:
1. Copy your photos into this folder.
2. Name them photo-01.jpg, photo-02.jpg, ... photo-06.jpg (or use .png).
3. Open pages/gallery.html.
4. For each photo card, change the image path from:
   ../assets/images/photos/photo-01-placeholder.svg
   to:
   ../assets/images/photos/photo-01.jpg
5. You can edit the captions directly below each image.

The six placeholder SVGs are intentionally included so the gallery looks complete before you add photos.
